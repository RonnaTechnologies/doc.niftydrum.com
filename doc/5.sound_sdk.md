# Sound SDK

## WaveTooEasy

The sound part of the board is based on the [WaveTooEasy](https://www.artekit.eu/doc/guides/wavetooeasy/){:target="_blank"} polyphonic WAV player from [ArteKit Labs](https://www.artekit.eu/){:target="_blank"}.
The main difference with the WaveTooEasy is that NiftyDrum+ uses a PCM5102A audio DAC, instead of the LM49450.
Because of that, and also because the board needed to have an analog input, the Artekit STM32F401 Core has been slightly modified.

## RonnaTech STM32F401 Core SDK

The SDK is 99% the same as ArteKit STM32F401 Core SDK.
