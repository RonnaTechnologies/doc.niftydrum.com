# Arduino

## That's a Blue Pill

NiftyDrum is powered by the **STM32F103C8T6** microcontroller, the same chip found in the iconic "**Blue Pill**" development board.

If you're unfamiliar with the Blue Pill, it’s a widely recognized and versatile board based on the STM32F103C microcontroller family. With **72MHz** clock speed, **64KB of flash** memory, and **20KB of RAM**, it offers plenty of flexibility for customization and experimentation.

## Arduino IDE

Because NiftyDrum is based on the same microcontroller as the Blue Pill, it is possible to program the board using the Arduino IDE.
But for that, you first need to have a C++ compiler that targets the STM32F1.

!!! warning
    In this section, it is assumed that you have already installed the Arduino IDE.

### ARM None-EABI toolchain

If you are a Linux user, you can install the **ARM None-EABI toolchain **directly from your package manager. The package is typically named **`gcc-arm-none-eabi`**.
For other platforms, download the official ARM toolchain from [Developer.arm.com](https://developer.arm.com/downloads/-/arm-gnu-toolchain-downloads){:target=_blank} – ARM GNU Toolchain Downloads. Make sure to select the correct version for your operating system.

### Arduino STM32 SDK

Assuming you have a working ARM None-EABI toolchain, you then need to get the Arduino STM32 RonnaTech SDK.

!!! note
    Although it is called Arduino STM32 RonnaTech SDK, the SDK is a fork of [Roger Clark's Arduino STM32 repository](https://github.com/rogerclarkmelbourne/Arduino_STM32){:target=_blank} with some minor modifications.

The SDK is pretty simple to install and configure.
Here is how to proceed:

- First, download and unzip the [Arduino STM32 RonnaTech SDK](https://ronnatech.com/sdm_downloads/arduino_stm32/){:target=_blank}.
- If you are a Linux user:
  - Go to your `home` diretory, then, into `Arduino` folder.
  - Create a new folder named `hardware` and move the `Arduino_STM32` into that folder.
- If you are a Windows user:

[Arduino STM32 SDK](https://ronnatech.com/sdm_downloads/arduino_stm32/){:target=_blank}

### Blink

```cpp title="blink.ino"
// the setup function runs once when you press reset or power the board
void setup() {
  // initialize digital pin LED _BUILTIN as an output.
  pinMode(LED_BUILTIN, OUTPUT);
}

// the loop function runs over and over again forever
void loop() {
  digitalWrite(LED_BUILTIN, HIGH);  // turn the LED on
  delay(1000);                      // wait for a second
  digitalWrite(LED_BUILTIN, LOW);   // turn the LED off 
  delay(1000);                      // wait for a second
}
```
